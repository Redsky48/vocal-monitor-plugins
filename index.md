# Vocal Monitor

**Vocal Monitor** is an Android app for live vocal pitch monitoring, recording, and effects. The app is paired with an open, community-driven registry of JavaScript audio plugins — this site is the human-readable face of that registry.

## Links

- 📋 [Privacy policy](./PRIVACY_POLICY.html) — what the app does and does not do with your data.
- 📦 [Plugin registry on GitHub](https://github.com/Redsky48/vocal-monitor-plugins) — source code, contribution flow, manifest.
- 📖 [Plugin API reference](./PLUGIN_API.html) — write your own JS plugin.
- ⚙️ [Native plugin API](./NATIVE_PLUGIN_API.html) — compile DSP-heavy plugins to DEX bytecode.
- 🏗️ [Architecture overview](./ARCHITECTURE.html) — how the three plugin runtimes fit together.
